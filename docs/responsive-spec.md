# Responsive Specification

## 1. Purpose

This document defines how Bruno Gätjens' portfolio should behave across different viewport sizes.

The current Figma provides the desktop design only.

Responsive behavior must therefore be intentionally designed rather than automatically generated by the coding agent.

The goal is to preserve:

- visual hierarchy
- artwork prominence
- typography relationships
- whitespace
- simplicity
- readability
- accessibility

Do not simply shrink the desktop design to fit smaller screens.

---

# 2. Responsive Philosophy

The responsive implementation should follow a progressive adaptation model.

Conceptually:

```text
Desktop
↓
Reduce available width
↓
Adjust spacing and columns
↓
Tablet
↓
Simplify layout
↓
Mobile
´´´
